# О проекте

Прошивка для отладочной платы **APM32F072VB Mini**.

В рамках тестового задания реализован проект переключением режимов работы светодиода и выводом отладочной информации, так-же сохранение его состояния в flash storage.

**Основные возможности:**
*   **Управление кнопкой:** Обработка нажатий через внешнее прерывание (EINT), с программным антидребезгом.
*   **Три режима мигания:** Переключение частоты мигания светодиода (LED).
*   **Логирование через UART:** Вывод текущего режима работы в последовательный порт (USART1) со скоростью 115200 8N1.
*   **Энергонезависимая память:** Сохранение текущего режима во внутреннюю Flash-память (FMC). После перезагрузки или отключения питания устройство восстанавливает последнее состояние.

## Сборка проекта

Клонируйте репозиторий:
```bash
git clone https://github.com/infrader/multitasking-generator-measurer.git
cd multitasking-generator-measurer
```
Создайте директорию для сборки и запустите CMake:

```bash
mkdir build
cmake -S . -B build
```
Соберите проект:

```bash
cmake --build build
```
В результате в папке build появится файл прошивки .elf / .bin / .hex.

Дальше выполните прошивку платы исходя из документации платы: https://www.geehy.com/uploads/tool/AN1080_APM32%20Series%20Tool%20Chain%20User%20Manual.pdf

## Принцип работы программы

1. **Инициализация (при старте):** Программа настраивает системную тактовую частоту, пины ввода/вывода (GPIO),
    таймер SysTick для отсчета миллисекунд, USART1 для логирования и внешнее прерывание (EINT) для кнопки. После этого из последней страницы Flash-памяти (FMC) считывается сохраненный режим работы.
2. **Основной цикл:** В бесконечном цикле `while(1)` программа отслеживает время для переключения светодиода (LED) с частотой,
    соответствующей текущему режиму (500 мс, 100 мс или 50 мс). Раз в секунду текущий режим отправляется в UART. Также в цикле проверяется флаг о том, что режим был изменен, и при необходимости новое значение записывается во Flash.
3. **Обработка кнопки (Прерывание):** При нажатии кнопки срабатывает внешнее прерывание. В обработчике `EINT0_1_IRQHandler` выполняется программный антидребезг (проверка времени с последнего нажатия).
    Если нажатие подтверждено, номер режима инкрементируется (1 -> 2 -> 3 -> 1), а также устанавливается флаг необходимости сохранения нового значения во Flash.
4. **Сохранение состояния:** Запись во Flash выполняется с использованием контроллера памяти FMC. Стирается одна страница,
   после чего в нее записывается «магическое» число (маркер валидности) и текущий номер режима. Это позволяет сохранять состояние при отключении питания.

Структура проекта
src/ — исходный код (main.cpp, button.cpp, logger.cpp, storage.cpp).

include/ — заголовочные файлы.

sdk/ — драйверы и библиотеки Geehy APM32F0xx StdPeriphDriver.

cmake/ — файлы тулчейна для сборки.

CMakeLists.txt — основной файл конфигурации сборки.
